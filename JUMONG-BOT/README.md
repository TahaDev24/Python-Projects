# JUMONG BOT

ربات تعاملی برای پیام‌رسان بله با الهام از جهان تاریخی جومونگ و گوگوریو. این پروژه چند تجربه بازی، روایت شاخه‌ای، آزمون و محتوای اطلاعاتی را در قالب منوهای تعاملی کنار هم قرار می‌دهد.

## قابلیت‌ها

- چهار تجربه تعاملی: تیراندازی با کمان، داستان جنگ، آزمون دانستنی‌ها و آزمون شخصیت
- روایت شاخه‌ای با مسیرهای تصمیم‌گیری مختلف
- بخش‌های محتوایی درباره شخصیت‌ها، مکان‌ها و داستان
- مراحل مبتنی بر انتخاب کاربر
- ثبت امتیاز و پیشرفت کاربران
- بخش‌های مخفی و مسیرهای ویژه قابل بازشدن
- منوی اصلی چندبخشی و مدیریت رویدادهای تعاملی

## ساختار فنی

- Python 3.9 یا بالاتر
- ارتباط مستقیم با Bale Bot API
- دریافت رویدادها با Long Polling
- ذخیره امتیازها در فایل JSON
- معماری تک‌فایلی
- استفاده از کتابخانه استاندارد Python

## راه‌اندازی

1. Python 3.9 یا بالاتر را روی محیط اجرا نصب کنید.
2. فایل `jumong_bot.py` را دریافت کنید.
3. توکن ربات را در بخش تنظیمات فایل قرار دهید؛ پیش از انتشار عمومی، توکن واقعی را از کد خارج و محرمانه نگه دارید.
4. برنامه را اجرا کنید:

```bash
python3 jumong_bot.py
```

برای اجرای آزمون داخلی:

```bash
python3 jumong_bot.py --selftest
```

## داده‌ها و امنیت

- فایل امتیازها در مسیر تعیین‌شده با متغیر `JUMONG_SCORES_FILE` ذخیره می‌شود؛ در صورت تنظیم‌نشدن، فایل JSON کنار برنامه قرار می‌گیرد.
- توکن ربات را در مخزن عمومی، Issue یا پیام عمومی قرار ندهید.
- برای آزمایش، از ربات و محیطی استفاده کنید که کنترل آن را در اختیار دارید.

## وضعیت آزمون

مستندات فعلی پروژه، وجود ۴۸ آزمون داخلی و بررسی ۱۱۲ مسیر/دکمه ناوبری را گزارش می‌کنند. این اطلاعات، گزارش ثبت‌شده در مستندات پروژه است و به‌معنای اجرای مجدد آزمون‌ها در این تغییر مستنداتی نیست.
