## Overview

This repository brings together standalone Python projects built for practical use and experimentation. It includes desktop-style utilities, SQLite tools, interactive messaging bots, and a strategy game for the Bale platform.

Each project has its own source file, requirements, setup instructions, and project-specific documentation. Choose a project below to get started.

## Getting started

These projects are independent. There is no single installation command or shared runtime for the entire repository.

1. Open the documentation for the project you want to use.
2. Check its Python version and dependencies.
3. Follow its installation and configuration steps.
4. Run the command listed in that project's guide.

> [!IMPORTANT]
> Some projects create local databases, logs, or user data. Back up important files before testing them. Never commit bot tokens, passwords, private identifiers, or real user data.
