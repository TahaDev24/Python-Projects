## شروع کار

## نکات مهم

- این مخزن شامل چند برنامه مستقل است؛ برای اجرای آن‌ها یک دستور واحد وجود ندارد.
- نسخه Python و وابستگی‌ها ممکن است بین پروژه‌ها متفاوت باشد.
- ربات‌های بله برای ارتباط با API به اینترنت و پیکربندی معتبر نیاز دارند.
- قبل از اجرای برنامه‌هایی که فایل یا پایگاه داده را تغییر می‌دهند، از داده‌های مهم نسخه پشتیبان تهیه کنید.
- هیچ توکن، رمز عبور یا شناسه خصوصی را در Commitها قرار ندهید.

## مشارکت
