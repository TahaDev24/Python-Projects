🗄️ DB MASTER PRO

ابزار حرفه‌ای مدیریت پایگاه داده SQLite با استفاده از Python و Kivy

DB MASTER PRO یک نرم‌افزار مدیریت پایگاه داده است که با هدف ساده‌تر، سریع‌تر و منظم‌تر کردن کار با دیتابیس‌های SQLite طراحی شده است.

این برنامه با رابط گرافیکی، امکان مشاهده و مدیریت جدول‌ها، اجرای دستورات SQL، ویرایش اطلاعات و انجام عملیات نگهداری پایگاه داده را فراهم می‌کند.

✨ قابلیت‌ها

- مدیریت پایگاه داده: باز کردن و مدیریت فایل‌های SQLite
- کاوشگر جدول‌ها: مشاهده جدول‌ها و ساختار آن‌ها
- نمایش اطلاعات: مشاهده و بررسی رکوردهای جدول‌ها
- ویرایشگر SQL: نوشتن و اجرای دستورات دلخواه SQL
- مدیریت رکوردها: افزودن و ویرایش اطلاعات
- مدیریت ایندکس‌ها: ایجاد ایندکس برای جدول‌ها
- پشتیبان‌گیری و بازیابی: تهیه نسخه پشتیبان و بازیابی فایل دیتابیس
- پشتیبانی از CSV: وارد کردن و خروجی گرفتن از اطلاعات
- نگهداری دیتابیس: بررسی سلامت، اجرای ANALYZE و VACUUM
- داشبورد مدیریتی: دسترسی به اطلاعات و ابزارهای اصلی برنامه
