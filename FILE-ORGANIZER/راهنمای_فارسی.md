# سازمان‌دهنده فایل‌ها (File Organizer)

یک ابزار ساده و گرافیکی برای مرتب‌کردن فایل‌های یک پوشه بر اساس نوع فایل، ساخته‌شده با Python و Kivy.

## امکانات

- انتخاب پوشه از طریق پنجره انتخاب فایل
- دسته‌بندی فایل‌ها بر اساس پسوند
- نمایش پیش‌نمایش قبل از انجام تغییرات
- انتقال فایل‌ها فقط پس از تأیید کاربر
- جلوگیری از بازنویسی فایل‌های هم‌نام؛ در صورت نیاز شماره به نام فایل اضافه می‌شود
- نمایش گزارش تعداد فایل‌های منتقل‌شده و خطاهای احتمالی
- بدون نیاز به اینترنت یا سرویس خارجی

## دسته‌بندی‌ها

| پوشه | نمونه پسوندها |
|---|---|
| تصاویر | PNG، JPG، GIF، WEBP |
| ویدیوها | MP4، MKV، MOV، AVI |
| صداها | MP3، WAV، AAC، FLAC |
| اسناد | PDF، DOCX، TXT، XLSX |
| فشرده‌ها | ZIP، RAR، 7Z |
| کدنویسی | PY، JS، HTML، CSS، JSON |
| نصب‌کننده‌ها | APK، EXE، MSI |
| سایر فایل‌ها | پسوندهای ناشناخته |

## پیش‌نیازها

- Python 3
- Kivy

برای نصب Kivy در محیطی که از pip پشتیبانی می‌کند:

```bash
pip install kivy
```

برای نمایش درست حروف فارسی در بعضی دستگاه‌ها، نصب این دو بسته هم پیشنهاد می‌شود:

```bash
pip install arabic-reshaper python-bidi
```

این دو بسته اختیاری‌اند؛ برنامه در نبود آن‌ها نیز اجرا می‌شود، اما ممکن است شکل حروف فارسی در بعضی محیط‌ها جدا از هم دیده شود.

## اجرا در ویندوز، لینوکس یا محیط دسکتاپ

```bash
python file_organizer.py
```

## اجرا در اندروید با Pydroid 3

1. مطمئن شو Kivy در Pydroid 3 نصب و قابل اجراست.
2. در تنظیمات اندروید، دسترسی فایل‌ها و رسانه‌ها را برای Pydroid 3 فعال کن.
3. فایل `file_organizer.py` را در Pydroid اجرا کن.
4. پوشه موردنظر را انتخاب کن، پیش‌نمایش را ببین و در صورت اطمینان مرتب‌سازی را تأیید کن.

نکته: دسترسی به بعضی پوشه‌های محافظت‌شده اندروید، حتی با فعال‌بودن مجوزها، ممکن است محدود باشد.

## نکات ایمنی و محدودیت‌ها

- برنامه فقط فایل‌های مستقیمِ پوشه انتخاب‌شده را بررسی می‌کند و وارد زیرپوشه‌ها نمی‌شود.
- فایل‌ها حذف نمی‌شوند؛ فقط به پوشه دسته‌بندی مربوط منتقل می‌شوند.
- هیچ فایلی بدون تأیید نهایی کاربر جابه‌جا نمی‌شود.
- فایل هم‌نام بازنویسی نمی‌شود و برای فایل جدید نامی مانند `photo (1).jpg` ساخته می‌شود.
- برنامه فعلاً قابلیت بازگردانی خودکار (Undo) ندارد. قبل از مرتب‌سازی پوشه‌های مهم، از اطلاعات ضروری نسخه پشتیبان بگیر.
