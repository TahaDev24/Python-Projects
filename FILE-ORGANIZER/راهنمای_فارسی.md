# File Organizer

A simple graphical tool for organizing the files in a folder by file type, built with Python and Kivy.

## Features

- Select a folder through a file picker
- Categorize files by extension
- Preview changes before applying them
- Move files only after user confirmation
- Prevent overwriting files with the same name; a number is added to the filename when necessary
- Display a report of the number of moved files and any potential errors
- No internet connection or external service required

## Categories

| Folder | Example Extensions |
|---|---|
| Images | PNG, JPG, GIF, WEBP |
| Videos | MP4, MKV, MOV, AVI |
| Audio | MP3, WAV, AAC, FLAC |
| Documents | PDF, DOCX, TXT, XLSX |
| Archives | ZIP, RAR, 7Z |
| Code | PY, JS, HTML, CSS, JSON |
| Installers | APK, EXE, MSI |
| Other Files | Unknown extensions |

## Requirements

- Python 3
- Kivy

To install Kivy in an environment that supports pip:

```bash
pip install kivy
```

To display Persian characters correctly on some devices, installing these two packages is also recommended:

```bash
pip install arabic-reshaper python-bidi
```

These two packages are optional. The application can also run without them, but Persian characters may appear disconnected in some environments.

## Running on Windows, Linux, or a Desktop Environment

```bash
python file_organizer.py
```

## Running on Android with Pydroid 3

1. Make sure Kivy is installed and working in Pydroid 3.
2. Enable file and media access for Pydroid 3 in Android settings.
3. Run `file_organizer.py` in Pydroid.
4. Select the target folder, review the preview, and confirm the organization if everything looks correct.

Note: Access to some protected Android folders may be restricted even when the required permissions are enabled.

## Safety Notes and Limitations

- The application scans only files directly inside the selected folder; it does not enter subfolders.
- Files are not deleted; they are only moved to their corresponding category folders.
- No file is moved without the user's final confirmation.
- Files with duplicate names are not overwritten. A new filename such as `photo (1).jpg` is generated instead.
- The application does not currently support automatic Undo. Back up important data before organizing important folders.
